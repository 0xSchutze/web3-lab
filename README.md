# web3-lab

Repository for applied smart contract vulnerability research.

---

## Background & Focus

This repository tracks my hands-on work in smart contract security. 

- **[`Shadow-Audits/`](./Shadow-Audits)** : Independent reproduction of Code4rena and Sherlock reports. Built to verify vulnerability mechanics via custom Foundry PoCs.
- **[`contracts/`](./contracts)** : (Archive) Core DeFi contracts built initially to understand their architecture before transitioning into security research.
- **[`ctf/`](./ctf)** : Foundational vulnerability challenges and basic exploitation scripts.
- **[`Notes/`](./Notes)** : Technical reference notes written alongside my work. Covers Solidity internals, DeFi mechanics, precision math, and security patterns.
