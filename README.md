# web3-lab

Personal learning repository. Documenting my path from Solidity fundamentals to smart contract security research — through building, breaking, and analyzing real protocols.

My approach to Web3 security is built on first principles: I build core DeFi mechanics from scratch strictly to gain the implementation-level knowledge needed to break them.

---

## Background & Focus

This repository tracks my hands-on work in smart contract security. 

- **[`contracts/`](./contracts) :** A small collection of standard DeFi primitives I built early on. These were written purely to gain the implementation-level knowledge needed for auditing.
- **[`Notes/`](./Notes) :** Technical reference notes written alongside my work. Covers Solidity internals, DeFi mechanics, precision math, and security patterns.
- **[`ctf/`](./ctf) :** Applied security work and challenge solutions, starting with Ethernaut (40/40 completed).
- **[`pocs/`](./pocs) :** *(Future/Active)* Standalone Foundry exploits and hack reproductions for vulnerabilities outside of standard CTF platforms.
- **[`hack-analysis/`](./hack-analysis)** : Real-world hack breakdowns with Foundry fork test reproductions.
