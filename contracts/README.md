# Foundational Contracts (Archive)

> **Note:** This directory is an archive of my initial learning phase. I no longer build or maintain protocols here.

Before diving into smart contract security and reverse-engineering, I spent my first few months writing these core DeFi primitives (AMMs, Vaults, Oracles, etc.) from scratch. 

The sole purpose of this phase was to acquire a deep, implementation-level understanding of Solidity, EVM mechanics, and standard protocol architectures. With this foundation established, my active work has completely shifted to vulnerability research and [Shadow Auditing](../Shadow-Audits/).

These contracts are not audited and serve purely as historical reference for my foundational learning.
